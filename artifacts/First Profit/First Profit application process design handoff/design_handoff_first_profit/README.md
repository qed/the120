# Handoff: First Profit — The 120 Interactive Application

## Overview
**First Profit** is The 120's application funnel: a parent lands from an ad, and within ~10 minutes their kid designs a real business (group → starter template → guided quiz → AI-shaped project page), sees the first 3 tasks and a projected "reveal," and the parent submits the dossier, sets a goal, and reserves a seat with a $250 refundable deposit through a Stripe checkout. The prototype covers the full journey landing → student arrival, for two demo children (Maya, G4, "Trail" skin · Theo, G7, "HQ" skin) under one parent account (David Okafor).

## About the Design Files
The files in this bundle are **design references created in HTML** — a working prototype showing intended look, copy, and behavior. They are NOT production code. The task is to **recreate these designs in the target codebase** (the real the120.school Next.js app) using its established patterns, components, and libraries. `First Profit.dc.html` is written in a declarative HTML-template + logic-class format; read it as a spec (all styling is inline; all copy is final).

## Fidelity
**High-fidelity.** Colors, type, spacing, radii, and copy are final and should be matched pixel-perfectly — except the prototype scaffolding listed under "Not product UI" below.

## The two registers (critical design system rule)
The funnel deliberately alternates between two visual registers:
1. **Application register (The 120 site system)** — paper `#f7f6f3`, ink `#131416`, red `#d92632`, blue `#0300ed`, blush `#efc5b8`; Georgia (serif, weight 400, italic accents) for display; **Space Grotesk** for body; **IBM Plex Mono** for eyebrows/labels/CTAs (uppercase, letterspaced); 10px-radius red CTA buttons; white floating nav card. Used for: landing, explainer/capture, Dashboard-Add Children, the dossier wizard, Next steps, checkout, arrival, and the close of the Reveal.
2. **First Profit app register** — the bound Path design system (`_ds/…` tokens + `ThePathDesignSystem_05a7ec` components: Button, Crest, Seal, ProgressMeter, ReviewPanel, StatusChip, Icon). Trail skin (parchment, warm, storybook) for grades 3–5; HQ skin (clean founder dashboard) for 6–12. Used for: handoff → doors → templates → quiz → compose → first-3-tasks → Reveal body, and Dashboard-post-signup.
The seam is intentional: the parent starts in the application register, hands the device over (screen switches to the child's skin), and gets it back at the Reveal's close ("Hand the device back; this part is for a parent").

## Interactions &amp; behavior
- **Application progress bar** (floating nav card, all screens explainer → submit): explainer 5/8/11/15% → addchild 20 → handoff 25 → doors 30 → templates 38 → quiz 46 → compose 55 → tasks 62 → reveal 70 → wizard 80/90/96 → submitted 100. Bar `#d92632` on `#eceae5`, 4px, width transition .35s. From the wizard on, the card also shows "NAME · SIGN OUT"; on Next steps/arrival it shows only name + SIGN OUT.
- **AI compose**: on quiz submit, call the LLM (see prompt in `Component.compose()`); regeneration limited to 2; every field editable afterward; fallback content on error. Guardrails: no em dashes, no promised outcomes, no dollar predictions, no invented facts about the child, no brand names, no emoji.
- **Reserve flow**: RESERVE SEAT - $250 (blue) → Stripe checkout → Pay → success → dashboard. Deposit state flips the child card status/CTA everywhere.
- **State-aware resume**: child-card CTAs route to the right screen for that child's state (handoff / reveal / apply / arrival).
- Buttons: hover darken slightly; disabled = `#d8d5cf` (application) — no other animation. Wax-stamp/pulse animations on Path screens come from First Profit DS motion tokens.

## State model
Per family: `parent {first,last,email}`, `captured`, seats (static 113). Per child: `added, name, grade, band (g3_5|g6_8|g9_12), skin (trail|hq), group, template, own, answers{love,make,cust,why}, project{name,desc,offer,cust,lines[5]}, regens, applied, goal, deposited`. Conversions: C1 email captured, C2 application submitted, C3 deposit paid, C4 tuition.
